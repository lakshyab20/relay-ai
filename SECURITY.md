# Security Policy

## Supported Versions

Security fixes are made against the latest version on the default branch. Older releases may not receive updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting for this repository when it is enabled. If private reporting is unavailable, contact the maintainers privately through GitHub.

Include the affected version or commit, steps to reproduce, and the impact. Avoid including real credentials or private user data in reports. We will acknowledge reports and coordinate a fix and disclosure timeline with the reporter.
